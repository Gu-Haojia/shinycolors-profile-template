# 立绘来源

`hana-coding.webp`：参考《偶像大师 闪耀色彩》鈴木羽那形象，通过 AI 图像生成与编辑制作的 Coding / 职场服装同人立绘，非官方原图。当前版本清理了部分头发的波纹高光，1024×1536，透明背景、无损 WebP。

原始角色相关权利归原权利人所有。本素材不在生成器代码的 MIT 授权范围内；详见 [第三方声明](../../THIRD_PARTY_NOTICES.md)。

在 `config.json` 中修改 `illustration` 可替换为自己有权使用的透明 PNG/WebP，也可设为 `null` 隐藏人物。原始生成中间文件、个人头像与个人统计不包含在模板仓库中。
